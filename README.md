# 戦国・城ディフェンス（仮）— defence castle

お城さんぽシリーズの3Dマップを使った、戦国時代の軽めのRTS（城を守る合戦指揮）。
名城に攻め寄せる大軍を、足軽・弓・騎馬の三すくみで迎え撃つ。小さな城から始め、最後は大坂の陣へ。

- 遊ぶ: https://32miya.github.io/defence-castle/ （スマホ優先・どの端末のブラウザでも）
- 負荷テスト: https://32miya.github.io/32miya-inuyama-castle/?battle&bench

## しくみ
タイトル・城選び（このリポジトリの `index.html`）→ 各城のお城さんぽのページを `?battle` 付きで開く → そのページがこのリポジトリの `battle/` を読み込んで合戦になる。
3Dマップは各城のさんぽのものをそのまま使い、合戦中だけ軽くする（城から離れた建物・木を捨てる、水面の映り込みと仕上げのぼかしを切る、影は一度だけ描く）。

| ファイル | 中身 |
|---|---|
| `index.html` | タイトル・城選び・遊び方（マップを読まない軽いページ） |
| `battle/stages.js` | ステージ一覧（犬山→松本→彦根→松山→備中松山→会津→姫路→熊本→安土→大坂、隠し：江戸） |
| `battle/sim.js` | 合戦の計算。部隊単位（三すくみ・士気・地形補正・武将の特技・波・勝敗・成長）。three.js を使わないので node でも動く |
| `battle/view.js` | 表示と操作。低ポリゴン兵士のインスタンシング（兵100人＝1体）、時間を止める指示、出陣前・結果画面、負荷テスト |
| `battle/battle.css` | 合戦画面のスタイル |
| `battle/maps/<城>.js` | 城ごとの設定データ（入口・進軍ルート・防衛線・配置場所・狭い門・敵の波・武将） |
| `tools/balance.js` | バランス確認 `node tools/balance.js -v`（隣に犬山城さんぽを置くか、CASTLE_HTML で index.html を指定） |

## 建物・塀を通らないしくみ
合戦の始めに、3Dマップの形（地面から0.9m以上の高さがある三角形）を上から見てマス目に塗り、建物・塀・櫓を「通れない所」にする。急な段差（石垣・崖）も通れない。
門の通り道（設定データの `gatePass`）・配置場所・ルートの点だけはあけておく。味方の移動も、敵の進軍ルート（設定データの点のあいだ）も、このマス目で最短の道を探す。
城ごとに建物の位置を書かなくてよい。

## 合戦の決まり（調整しやすい数字は battle/sim.js の DEF）
- 城方の補正: 守り手は受ける損害0.6倍・攻撃1.15倍（defTake・defAtk）
- 堀: だれでも渡れるが速さ半分（waterSpeed）。堀の中の兵は攻撃0.6倍・受ける損害1.3倍
- 塀（厚さ3m以下の細いもの）: 攻め手だけよじ登れる。速さ0.3倍（wallSpeed）・攻撃0.5倍・受ける損害1.5倍。建物はだれも通れない
- 敵の兵数: 設定データの scale × ステージごとに+20%（stageGrow）
- 部隊の数: 城の門（入口）の数＋3。兵の総数を足軽4割・弓3割強・騎馬2割半で自動編成（formArmy）。配置は設定データの deploy の順
- 敗走した敵は来た道（進軍ルート）をさかのぼって引き返す

## 城を増やすとき
1. `battle/maps/<id>.js` に設定データを書く（`inuyama.js` が見本）
2. その城のさんぽの `index.html` に合戦モードの入口を入れる（犬山城さんぽの `BATTLE` の部分と同じ数行。`OB_MAP` を城のidに）
3. `battle/stages.js` のその城に `url` を足す

セーブ（攻略状況・軍勢）は端末のブラウザに保存（`oshiroBattle.v1`）。同じ 32miya.github.io の中なので、どの城のページからも共通。

# 世界さんぽディフェンス（タワー配置型）— `world/`

世界さんぽシリーズの3Dマップを使った、別のゲーム。塔・城壁・投石機を置いて、魔物の群れから城の奥の「聖なる泉」を自動で守る定番のタワーディフェンス。敵は史実の軍勢ではなくファンタジーの魔物（ゴブリン・オーク・トロル・ワイバーン・竜など）。

- 遊ぶ: https://32miya.github.io/defence-castle/world/
- 負荷テスト: https://32miya.github.io/heidelberg-castle-sanpo/?td&bench

## しくみ
スタート画面（`world/index.html`）→ 各名所の世界さんぽのページを `?td` 付きで開く → そのページが `world/` を読み込んで防衛戦になる。
3Dマップは世界さんぽのものをそのまま使い、防衛中だけ軽くする（戦う範囲から外れた三角形・木を捨てる、人を消す、影は一度だけ描く）。

| ファイル | 中身 |
|---|---|
| `world/index.html` | タイトル・ステージ選び・遊び方（マップを読まない軽いページ） |
| `world/stages.js` | ステージ一覧（ハイデルベルク→ウィンザー→…→アトランティス） |
| `world/td.js` | 本体。塔・敵・波・弾・流星、低ポリゴンの魔物（インスタンシング）、タップ配置・ピンチ・回転のカメラ、画面 |
| `world/td.css` | 防衛画面のスタイル |
| `world/maps/<名所>.js` | 名所ごとの設定データ（進軍ルート・空のルート・塔を置ける場所・城壁の場所・泉・カメラ） |

## 決まり（調整しやすい数字は td.js の TW・EN・WAVES）
- 塔: 弓の塔（速い・空も撃てる）、投石機（範囲・空は撃てない）、魔法の塔（鎧を通す・足止め・最大で連鎖）、城壁（道をふさぐ。壊れたら建て直し）。各3段階に強化、売ると7割戻る
- 波: 全10波。波が出そろうと35秒の秒読み、早めに呼ぶと金貨。ステージが進むごとに体力+22%・数+10%
- 流星: 地上の敵をまとめて焼き、足を鈍らせる（40秒待ち）
- ★: 結界を9割以上残して3つ、半分以上で2つ

## 名所を増やすとき
1. `world/maps/<id>.js` に設定データを書く（`heidelberg.js` が見本）。進軍ルートはさんぽの道探し（`navFind`）で求めて間引くと、建物や堀を通らない道になる
2. その名所の `index.html` に防衛モードの入口を入れる（ハイデルベルク城さんぽの「世界さんぽディフェンスの入口」の数行と、`loop` の `TD` の1行）。`window.__sekai` に場面・カメラ・地面の高さ（`hy`）・時代の切り替え（`setEra`）を渡す
3. `world/stages.js` のその名所に `url` を足す

セーブ（★・クリア）は端末のブラウザに保存（`sekaiDefense.v1`）。
